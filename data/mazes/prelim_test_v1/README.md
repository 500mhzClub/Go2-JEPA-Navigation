# prelim_test_v1: the preliminary test mazes

Capability layouts 30-89 (`configs/mazes/capability_v1.yaml`), two episodes each. Every result on them is preliminary.

These 60 mazes were generated as the capability programme's sealed test set. On 1 October 2026 they were declassified
for the development-mode preliminary run and renamed `prelim_test_v1`. Their files keep the role name they were
generated with (`"role"` / `"data_role": "sealed_test"`), so that regenerating the set reproduces them byte for byte
and records of the original runs on them still match. The role name is historical: nothing in this set is sealed.

The rigorous-phase test set that replaces them was generated separately and is not part of this repository.
